# Avatar GLB (Mixamo)

Coloca aquí el archivo **`avatar.glb`** para el personaje jugable.

## Descarga desde Mixamo

1. Crear cuenta gratuita en [mixamo.com](https://www.mixamo.com).
2. Elegir personaje **Y Bot** o **Remy**.
3. Descargar animaciones (FBX o glTF):
   - Idle
   - Walking
   - Running
   - Jumping
4. Unificar en un solo `.glb` con Blender (addon Mixamo Rig en `assets/mixamo_rig/`) o herramienta glTF.
5. Guardar como `public/assets/models/avatar.glb`.

Si el archivo no existe, el juego usa una cápsula placeholder colisionable.
